Put your own game files directly in this folder (nothing of the game is included in this program).

GAME DATA (one of these two is needed)

  DOW
    Hard-disk data file from Pera Putnik's HDD conversion (Atari ST).
    Size 819200 bytes, CRC32 6703B50F.

  Dogs of War (1989)(Elite)[cr Replicants][t].st
    Atari ST disk image, Replicants crack (trained). The file name can be anything ending in .st.
    Size 829440 bytes, CRC32 F6E84D7A.

AMIGA MUSIC (optional: adds the Amiga music to the Music menu)

  Dogs of War (1989)(Elite)[cr].adf
    Amiga disk image. Size 901120 bytes, CRC32 09E02A3E.

  Dogs Of War.lha
    WHDLoad package of the Amiga version. What identifies it is the disk image it contains, Disk.1:
    size 711680 bytes, CRC32 2428BB3B (the checksum of the .lha file itself is not used).

  The Amiga files are recognised by their content, not by their names: the program looks, inside the .adf or inside
  the Disk.1 of the .lha, for the 61166 bytes of the sound driver (CRC32 8F60BEBA), so other dumps of the same Amiga
  game that hold the same data also work.

The checksums are CRC32 of the whole file (of the Disk.1 image for the .lha), as shown by any checksum tool.
